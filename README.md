# Learning Management System (MERN Stack)

This Learning Management System (LMS) MERN stack app enables:

- **Educators** to:
  - Create, manage, and monetize educational content
  - Use a role-based interface tailored for teaching

- **Students** to:
  - Browse and purchase courses
  - Consume content with progress tracking
  - Access a student-focused interface

## Features

- 💳 **Secure Payment Processing** with **Stripe**
- 📺 **Video Streaming** via **YouTube Integration**
- 🔐 **Role-Based Interfaces** for both students and educators
